Libraries and data

Language and data
all-MiniLM-L6-v2 fp16
The sentence-embedding model behind the “embedding” score, run in your browser. It turns each word (and each word plus its definitions) into a vector; linxicon.com says it uses the same model.
WordNet 3.0
Dictionary of meanings and relations: synonyms, derived forms, “kind of”, part/whole and compounds. It also supplies the definitions for shared-context profiles and decides which words are playable.
ConceptNet Numberbatch 19.08
Common-sense word vectors. They drive the “ConceptNet” score, match words inside shared context, add words WordNet lacks (paperless), and their term list supplies curated phrases.
ConceptNet 5.7
The common-sense knowledge graph Numberbatch is built from.
Wikipedia article titles
Every English article title, filtered to two-word phrases (“fantasy football”, “transfer of power”) for the phrase signal.
In your browser
Transformers.js 4.3.0
Runs MiniLM locally in a background thread, so no server is needed.
ONNX Runtime Web 1.31
Does the model’s math in WebAssembly, loaded by Transformers.js.
vis-network 9.1.9
Draws, animates, zooms and pans the boards. It’s the same library linxicon.com uses, which is why the zoom matches.
Building and checking the data (Python)
sentence-transformers 6.1.0
Runs MiniLM in the Python reference engine that the browser version is tested against.
PyTorch 2.14.1
Does the model’s math under sentence-transformers.
Hugging Face Transformers 5.20.2
The model architecture and tokenizer sentence-transformers builds on.
Hugging Face Hub 1.33.0
Downloads the model weights.
NLTK 3.10.3
Python access to WordNet; the browser’s WordNet lookups are exported from it and checked against it.
NumPy 2.5.4
Vector math for the reference engine, and the compact int8 format the ConceptNet vectors ship in.
Python standard library 3.14
http.server previews the page locally; gzip and json write the data files.
Research only
google-10000-english
Common English words, used to sample random pairs when probing linxicon.com’s scoring.
